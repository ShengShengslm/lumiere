## Public-domain torn edge

`cc0-torn-edge-mask.png` is the “Perforated Paper Edge Mask” published on
OpenGameArt. The source page marks the asset CC0:

- Source: https://opengameart.org/content/perforated-paper-edge-mask
- Image: https://opengameart.org/sites/default/files/perforatededgemasktorn.png
- License: https://creativecommons.org/publicdomain/zero/1.0/

The interface uses the photographed edge as a mask on the journal note. This
keeps the rough paper fibers without importing poster text or unrelated artwork.

## Public-domain torn paper contour

`cc0-torn-paper-sheet.png` is the free 1920px “Torn White Paper Png” published
by PublicDomainPictures and marked CC0 Public Domain:

- Source: https://www.publicdomainpictures.net/en/view-image.php?image=678095&picture=torn-white-paper-png
- Image: https://www.publicdomainpictures.net/pictures/680000/velka/torn-white-paper-png-1742924698uTx.png
- License: https://creativecommons.org/publicdomain/zero/1.0/

`scripts/process-journal-assets.py` samples different sections of that real
alpha contour to build `torn-mask-note-a.png`, `torn-mask-note-b.png`, and
`torn-mask-fragment.png`. Each mask therefore has a different photographed
edge rather than a repeated CSS polygon.

## Derived specimen assets

The following transparent cutouts are derived from the owner-supplied source
images. They remove phone-screenshot chrome and white/black fields, lower
saturation, and keep only the botanical subject:

- `botanical-moth-cutout.png`
- `botanical-rosemary-cutout.png`
- `botanical-leaf-cutout.png`
- `botanical-rose-cutout.png`
- `botanical-lotus-specimen-v2.png`

The lotus specimen was edited with the built-in image generation tool using
`user-dried-lotus-a.png` as the edit target. The prompt required preserving the
four-pod arrangement while removing the screenshot UI and gold effect, placing
the result on a flat magenta key. The project-local chroma-key helper then
converted that key to alpha. The other cutouts are deterministic crops from the
owner-supplied materials and can be regenerated by running:

```powershell
python .\scripts\process-journal-assets.py
```
